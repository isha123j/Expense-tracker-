# 💸 Expense Tracker CLI Application

A user-friendly **Command Line Expense Tracker** built with **Python**, featuring graphical insights, a currency converter, and cloud-ready storage. Ideal for managing daily expenses locally with the power of visual reports and flexible tracking.

---

## 📌 Features

- ✅ Add, update, and delete expenses
- 📊 Visualize expenses by category/date using **Matplotlib**
- 🌍 Built-in **Currency Converter** (USD ↔ INR or any)
- 🧠 Monthly expense summaries
- ☁️ Cloud backup (via Google Drive/Dropbox – optional)
- 📁 Export to **CSV/Excel** format
- 🧪 Fully CLI-driven with clean user experience
- 🔐 Environment variable-based config for secure API usage

---

## 🛠️ Tech Stack

| Technology       | Use                                 |
|------------------|--------------------------------------|
| Python 3         | Core language                        |
| SQLite           | Local database                       |
| Matplotlib       | Expense graphs                       |
| forex-python     | Currency conversion                  |
| Google Drive API | Optional cloud sync                  |
